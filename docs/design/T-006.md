# Design — T-006: Credit prequal adapter — pass-through mock (token + prequal results only)

- **Task:** `tasks/T-006-credit-prequal-adapter-mock.md`
- **Spec basis:** `specs/01-consumer-product-spec.md` — "Credit data residency (resolved 2026-08-07)"; `specs/00-shared-core-architecture.md` — "Integrations — anti-corruption / adapter layer (shared)", "Flag engine (shared)" (qualified-rate input)
- **ADRs honored:** ADR-001 (Node/TS, one toolchain, vitest), ADR-002 (flag vocabulary — consumed, not defined, here), ADR-003 (npm workspaces), ADR-004 (`@deal-copilot/*` marker names, bare import aliases)
- **Spine contract implemented:** `CreditPrequalAdapter` / `PrequalResult` from `@core` (`packages/core/src/adapters.ts`, designed in `docs/design/T-001.md` §3.2/D4) — **referenced, never redefined**
- **Stage:** design → build
- **Scope:** `packages/adapters/credit-prequal/**` only. Mock-only (`mock_only: true`). No HTTP, no provider SDK, no credentials, no storage machinery.

## 2. Public API — exact interface signatures (`src/index.ts` surface)

Everything below speaks **only** in `@core` types. The spine contract (`CreditPrequalAdapter`, `PrequalResult`, `AdapterResult`, `AdapterError`, `AdapterErrorCode`, `MoneyCents`, `IsoTimestamp`) is imported from `@core` and never re-declared (ADR-001 "defined once").

```ts
import type {
  AdapterErrorCode,
  CreditPrequalAdapter,
  IsoTimestamp,
  MoneyCents,
} from '@core';

/** Adapter id used as `source` on results and errors. */
export declare const MOCK_CREDIT_PREQUAL_SOURCE: 'mock-credit-prequal';

/**
 * What a completed hosted flow can resolve to. Note what is NOT here: no
 * score, no report, no tradelines, no applicant identity — the type has no
 * field where raw credit data could fit (specs/01 "Credit data residency").
 */
export type PrequalScenario =
  | {
      kind: 'approved';
      /** Percent, e.g. 6.9 — same unit convention as Offer.apr (D4). */
      qualified_apr: number;
      approved_amount_max: MoneyCents;
    }
  | {
      /** Declined / no offers — surfaces as `not_found` per D1. */
      kind: 'no_offer';
    }
  | {
      /** Simulated provider-side failure, for exercising caller error paths. */
      kind: 'provider_error';
      code: Extract<
        AdapterErrorCode,
        'auth' | 'rate_limited' | 'provider_unavailable' | 'malformed_response'
      >;
    };

/** One named hosted-flow outcome the mock can produce. */
export interface PrequalFixture {
  /** Opaque scenario id; the ONLY thing the mock hosted flow accepts (D2). */
  scenario_id: string;
  scenario: PrequalScenario;
}

/** Default fixture set: prime / near-prime / no-offer / one of each error code. */
export declare const DEFAULT_PREQUAL_FIXTURES: readonly PrequalFixture[];

export interface MockCreditPrequalOptions {
  /** Defaults to DEFAULT_PREQUAL_FIXTURES. */
  fixtures?: readonly PrequalFixture[];
  /** Injectable clock for fetched_at (D3). Defaults to system time. */
  now?: () => IsoTimestamp;
}

/**
 * Simulates the PROVIDER side of the hosted flow: the applicant completes the
 * provider's hosted UI (where the soft pull happens — outside our systems)
 * and our side receives back an opaque token. Input is a scenario id only —
 * structurally no applicant or credit fields (D2).
 */
export interface MockHostedFlow {
  /** Returns the provider_token redeemable via CreditPrequalAdapter.getPrequal. */
  complete(scenario_id: string): { provider_token: string };
}

export interface MockCreditPrequal {
  /** The ONLY thing core services / composition roots receive (specs/00 anti-corruption). */
  adapter: CreditPrequalAdapter;
  /** Test/demo harness — never handed to core services. */
  hostedFlow: MockHostedFlow;
}

export declare function createMockCreditPrequal(
  options?: MockCreditPrequalOptions,
): MockCreditPrequal;
```

Boundary rules this encodes:

- **Callers see `CreditPrequalAdapter` and nothing else.** `PrequalScenario` / `PrequalFixture` / `MockHostedFlow` are the mock's control surface for tests and composition roots; no core service imports them, and none of them is a provider (Array/Plaid/MeasureOne/bureau) shape — task AC-3 / specs/00 "Core services never see a provider's shape."
- **The forbidden thing is inexpressible.** The adapter's single method returns `AdapterResult<PrequalResult>`; `PrequalResult` (frozen in `@core`) has exactly four fields: `provider_token`, `qualified_apr`, `approved_amount_max`, `fetched_at`. Neither this package's fixture types nor its outputs have anywhere to put report contents, tradelines, or scores — task AC-2.
- **No live-provider affordances.** No URL, endpoint, credential, or SDK type appears in any signature. Credential absence is the structural enforcement (CLAUDE.md "Approved integrations").

## 4. Error paths per operation

### 4.1 `adapter.getPrequal(provider_token)` — the only operation

Behavior follows the binding T-001 §5.1 table; rows below are its instantiation for this adapter.

| Failure mode | Result | Retryable | Logged (log-safe only) | Surfaces as |
|---|---|---|---|---|
| Empty / non-string / structurally blank token | `{ok:false, code:'invalid_input'}` | No — caller bug | code, source | Validation error to caller; fix upstream |
| Unknown token (hosted flow never completed, or expired) | `'not_found'` | No — terminal | code, source | "Complete prequal to see your qualified rate" state |
| Scenario `no_offer` (declined / no prequal offers) | `'not_found'` (D1) | No — terminal | code, source | "No prequal offers available"; flag engine runs without a qualified-rate input (its `rate_markup` rule simply has no comparand) |
| Simulated credential failure | `'auth'` | No; operator alert | code, source | Degraded-feature state (prequal unavailable) |
| Simulated rate limit | `'rate_limited'` | Yes — caller backoff + jitter | code, source | Retry silently; degraded state if exhausted |
| Simulated outage / timeout | `'provider_unavailable'` | Yes — caller backoff | code, source | Same as above; previously stored `PrequalResult` (timestamped) remains usable |
| Fixture shape drift (fixture carrying fields outside `PrequalScenario`, detected at factory load) | `'malformed_response'` | No; operator alert — the mock contract broke | code, source | Degraded-feature state |

**Retry / idempotency:** `getPrequal` is a pure read — naturally idempotent. Retries are always safe; the same token deterministically resolves to the same scenario outcome (D3: only `fetched_at` reflects call time). No caller-supplied idempotency key is needed (that machinery belongs to outbound sends, T-001 §5.4, not reads).

**Never logged, by contract:** token values, APRs, approved amounts, fixture contents, or anything applicant-shaped. `AdapterError.message` is defined log-safe/PII-free in `@core`; this design additionally keeps `provider_token` out of messages — the token is a capability handle and logs are not a place for capabilities. Log lines carry `source: 'mock-credit-prequal'`, the error code, and a static description only.

**Never thrown:** the adapter returns `AdapterResult` for every input including garbage (`null`, objects, oversized strings) — verified by test (§5).

### 4.2 `hostedFlow.complete(scenario_id)` — mock harness only

- Unknown `scenario_id` → throws synchronously in the test harness (this is test-fixture misuse, not an adapter-boundary failure; `AdapterResult` discipline applies only at the adapter boundary).
- Deterministic: same `scenario_id` → same token (D5).

### 4.3 Webhooks — none exist here (and the rule that binds them anyway)

This package exposes **no webhook handler, HTTP route, or callback endpoint** — the mock is pull-only, and `mock_only: true` forbids live endpoints. Stated for completeness per the design brief: if a future live credit provider delivers hosted-flow completions by webhook, that handler lives in a service (not this adapter package), and it is bound by the T-001 §5.2 **ack-then-queue** contract: synchronous pure parse → durably enqueue → ack 2xx; parse failure still acks and quarantines; only enqueue failure returns 5xx; dedupe on the provider's message ref. Nothing in this package's shapes obstructs that pattern — `getPrequal` is the post-event pull a queued consumer would make. Building that handler (and the live adapter behind it) requires Corban-signed credentials first (CLAUDE.md mock-only list).

## 5. Test design (`test/credit-prequal.test.ts`, co-located vitest — AC-4)

Runs from root: `npx vitest run packages/adapters/credit-prequal`. Fixed clock injected throughout.

1. **Hosted-flow round trip (fixtures):** `complete('prime')` → token → `getPrequal(token)` → `{ok:true}` with the fixture's `qualified_apr` / `approved_amount_max`, `source === 'mock-credit-prequal'`, `fetched_at` from the injected clock. Repeat for a second fixture (distinct values) to prove token→scenario mapping.
2. **Serialization leak check:** `Object.keys(result.value).sort()` equals exactly `['approved_amount_max','fetched_at','provider_token','qualified_apr']`; `JSON.parse(JSON.stringify(value))` round-trips unchanged with no additional keys — nothing beyond token + prequal fields exists on outputs.
3. **Type-level leak check:** `expectTypeOf<keyof PrequalResult>()` is exactly the four-key union; type-level assertions that no key named `score`, `report`, `tradelines`, `ssn`, or `applicant` exists on `PrequalResult`, `PrequalScenario`, or `MockHostedFlow['complete']` parameters; `getPrequal`'s return type is `Promise<AdapterResult<PrequalResult>>` and nothing wider.
4. **Error table coverage:** one test per §4.1 row — invalid input, unknown token, `no_offer` → `not_found`, each simulated provider error code with the correct `retryable` boolean.
5. **Never-throws:** `getPrequal` called with garbage inputs resolves (never rejects/throws) to `{ok:false}`.
6. **Determinism / idempotency:** two calls with the same token yield identical values; distinct clock injections change only `fetched_at`.

| Webhooks ack-then-queue; no dropped messages (specs/00) | N/A directly — no webhook surface here | §4.3 records the binding pattern for any future live-provider callback and keeps this package free of HTTP surfaces that could tempt inline work |
| File-ownership / frozen roots (CLAUDE.md) | Editing root configs or another task's files | Files created are exactly §1's list inside `packages/adapters/credit-prequal/**`; alias + test globs were predeclared by T-001, so no root edit is needed |
